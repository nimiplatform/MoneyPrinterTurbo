# MoneyPrinterTurbo for Nimi

Nimi Desktop から、テーマまたは台本、ローカル・ストック・AI 素材、音声、実際の時間情報を持つ字幕、音楽を使って短い動画を制作します。

条件と利用可能な範囲は [NIMI_APP.md](NIMI_APP.md)、実装と実行済みの検証範囲は [NIMI_ADAPTATION.md](NIMI_ADAPTATION.md)、Host 自動化は [操作ガイド](docs/skill/SKILL.md) を参照してください。未実行の経路は NOT-VERIFIED として記載しています。

AI の設定と認証情報は Nimi が管理します。素材サービスと Upload-Post の業務アカウントは App が管理します。Desktop が監督する Electron Host を使用してください。従来の Streamlit、独立 API、Docker、Python CLI と AI provider は廃止しました。

元の [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) の MIT [LICENSE](LICENSE) と Git 履歴を保持しています。
